## Core idea

`[MECHANISM FRAME]`

A closure node is a configuration where a local structure reaches high internal
resolution. In chemistry, the relevant public example is the redox-richness
profile around subshell closure positions.

The empirical object is not merely the count of oxidation states. The object is
the profile of accessible redox states relative to closure positions.

## d-block reading

`[POST-AUDIT / COMPACT ENCODING]`

In the d-block, redox richness is treated as approximately node-centered around
the half-filled d5 configuration under the representative-state protocol used
in the paper.

The post-audit status is narrower. `d_balance` compactly encodes the known
half-filled-shell symmetry. It beats linear or monotonic baselines, but it does
not establish predictive novelty against fair quadratic filling baselines.

## f-block reading

`[NEGATIVE / STRESS TEST]`

In the lanthanide f-block, the qualitative profile appears more peripheral:
the half-filled f7 configuration is comparatively rigid, while additional
states cluster around neighboring configurations.

Subsequent actinide `f_balance` and static `s:d:f` fraction tests did not
establish novelty. The f-block material should be treated as a stress-test
boundary, not as supporting validation.

## Mechanism claim

`[HYPOTHESIS]`

The two profiles are proposed as two regimes of one event:

- soft node: unresolved difference can be registered locally;
- hard node: unresolved difference is projected to neighboring configurations.

The missing control variable is node hardness. The mechanism remains open until
node hardness can be operationalized independently from the oxidation-state
profiles it is meant to explain.

## Future test boundary

`[OPEN / PRE-REGISTER BEFORE FITTING]`

Future tests need an independently defined node-hardness criterion and locked
oxidation-state sources before fitting. If those tests fail, the framework
should remain a descriptive mechanism language rather than a predictive
chemistry model.

## Public boundary

This brief may be shared as a conceptual companion, but it should not be used
to claim that ROSI or RGM has derived chemical redox behavior from first
principles or validated a superior redox predictor.
