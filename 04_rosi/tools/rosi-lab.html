ROSI Lab / browser sandbox

Compare routes without exposing the core.

Paste a problem and two to five candidate answers, hypotheses, or routes. This public sandbox extracts simple roots in the browser and returns a route audit: conserved roots, residue, new roots, and discriminating information to request next.

This is not the full ROSI engine and it does not send data to a server. It is a safe public prototype for gathering structured examples before a private API is connected. Do not paste private, sensitive, or confidential information.
