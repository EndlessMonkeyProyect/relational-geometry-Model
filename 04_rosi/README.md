# 04 - ROSI

ROSI - Relational Orientation System for Information - is the computational
companion to this research map.

The active implementation lives in its own repository:

https://github.com/EndlessMonkeyProyect/ROSI

Zenodo:

- Latest metadata record: https://zenodo.org/records/20363352
- Concept DOI: `10.5281/zenodo.20302934`
- Earlier file-bearing version: https://zenodo.org/records/20302935

This folder is reserved for bridge notes, runnable examples, and future tools
that should be kept close to the Relational Geometry model without duplicating
the full ROSI codebase.

## Public shareable layer

Shareable ROSI material lives in:

[`shareable/`](shareable/)

This subfolder contains public briefs, schemas, and collaborator prompts that
can be sent to reviewers or other AI systems without exposing the ROSI core.

It intentionally excludes private scoring, internal prompts, provider
configuration, benchmarks, API keys, and the protected implementation.
