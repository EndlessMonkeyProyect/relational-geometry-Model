# lyo_bench critique — resolution note

The lyo_bench critique is accepted as methodologically correct.

Resolved points:
1. `d_balance` must not be compared only to linear electron count.
2. The fair baseline is a quadratic in `N_d` or `|N_d-5|`.
3. RMSE differences must be bootstrapped at the same granularity as LOSO: by series block.
4. The source of oxidation-state counts and the model set must be locked before fitting.
5. The current conclusion is compact encoding, not predictive novelty.

This note should be included as an appendix or supplement, not as an academic citation.
