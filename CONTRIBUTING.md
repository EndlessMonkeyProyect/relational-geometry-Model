# Contributing

This repository invites critique before agreement.

Useful contributions include:

- consistency objections;
- reproduction attempts for numerical claims;
- independent derivations or counter-derivations;
- clearer notation, naming, or diagrams;
- issue reports for broken links, duplicated files, or provenance gaps.

When opening an issue, please name the folder and document involved, then state
the smallest claim that appears unsupported, ambiguous, or falsified.

For large changes, open a branch or pull request rather than editing `main`
directly.
